# Aurora model viewer HDR environments

The bundled 1K HDR environments are sourced from Poly Haven and are released
under CC0. Aurora uses them only for model lighting and reflections; the page
background remains the Aurora interface background.

- `studio-neutral-1k.hdr`: `studio_small_03_1k.hdr`
- `studio-soft-1k.hdr`: `poly_haven_studio_1k.hdr`
- `outdoor-dawn-1k.hdr`: `kiara_1_dawn_1k.hdr`
- `city-night-1k.hdr`: `potsdamer_platz_1k.hdr`
