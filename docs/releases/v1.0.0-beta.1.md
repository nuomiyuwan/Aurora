# Aurora 1.0.0 Beta 1

这是 Aurora 首个公开源码技术预览版本，包含本地视频资料库、帧环浏览、三维模型查看、统一探索、AI 画面检索以及可选的在线视频平台适配。

## 已知限制

- macOS 安装包仅使用 ad-hoc 签名，尚未完成 Developer ID 签名和 Apple 公证，Gatekeeper 可能提示无法验证。
- Windows 安装包尚未使用 Authenticode 商业签名，SmartScreen 可能提示未知发布者。
- 在线来源依赖各平台官方网页结构与规则，平台更新后可能需要重新适配。

安装与安全提示见仓库根目录 `README.md`。
